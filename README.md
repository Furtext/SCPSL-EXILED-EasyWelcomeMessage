# SCPSL-EXILED-EasyWelcomeMessage
This is just a basic EXILED plugin that allows you to show a welcome message to players when they join.

# HOW TO INSTALL

After you download the file, just place it into the EXILED Plugins folder.

Default Location: "C:\Users\[username]\AppData\Roaming\EXILED\Plugins"

Also you can install Exiled from here: "https://github.com/ExMod-Team/EXILED"

# HOW TO CONFIGURE

After you launch your server with the plugin, there should be a config file inside the EXILED folder.

Default Location: "C:\Users\[username]\AppData\Roaming\EXILED\Configs\Plugins\easy_welcome_message"

Inside that folder, you will find a file like "7777.yml" (the numbers will be the same as your server port). Inside that file, you can edit 
the message and its duration.

If you want to make customized messages (like colored, bold, etc.), you can use text tags like '<color=></color>'. You can find all of them on this website:
"https://docs.unity3d.com/6000.3/Documentation/Manual/UIE-supported-tags.html"

Also, if you want to add emojis to your message, you can use this website:
"https://emojidb.org" (Don't try to copy from Discord, etc.—use this website).
